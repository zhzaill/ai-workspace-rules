# AI Workspace Rules

一套让 AI 快速理解、维护和复刻文件工作区的通用管理规则。

它把工作区管理拆成四层：

1. **入口索引**：先读总规则，再按任务读取专属规则。
2. **任务分流**：按目录职责放置项目、数据、工具、归档、备份和日志。
3. **证据闭环**：下载、安装、远程修改和生成产物都要验证结果。
4. **状态追加**：状态和日志保留判断链，错误用更正追加，不覆盖历史。

## 快速使用

复制 [`docs/ai-replication-quickstart.md`](docs/ai-replication-quickstart.md) 到工作区的规则目录，并把它作为新 AI 会话的第一份导航文档。然后将其中的目录名、状态文件路径和领域专属入口替换为当前工作区实际值。

## 适用范围

- AI 辅助维护的个人工作区、项目集合或多仓库目录
- 需要区分源代码、数据、缓存、构建产物和备份的环境
- 需要让不同 AI 会话共享状态、证据和操作边界的工作流

手册不规定具体工具或平台；Git、PowerShell、ComfyUI 等内容都应作为可选的领域扩展加入，而不是写入所有工作区的全局规则。
